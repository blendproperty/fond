# FOND mobile design preview — 1 October 2026

Standalone, clickable design proposal. Run a local static server in this directory and open index.html#fond. index.html also provides a desktop phone frame and screen selector links.

Scope: compact image-free FOND landing page before the ordering menu; Figtree, Midpoint Ink, FOND Oxblood and warm paper; shared Home/FOND/Gym/Padel/Functions navigation throughout; landing pages for every home destination, with Car Wash and Suites explicitly coming soon. Menu includes horizontal favourites, searchable item rows, category tabs and category links, sold-out treatment, customisation, quantity and sample basket. Additional service actions show preview detail screens only.

Boundary: no API calls, booking, payment, registration, outbound messages or persistence. Menu prices and options are samples, not a verified export of the current editable production database. Food artwork is illustrative SVG; final food photography requires approved assets. Rewards and hours are sample concepts. Existing Hub photographs and logo are copied from public assets. Trading availability must come from live configuration in implementation.

Validation: verify.cjs uses the repository's Playwright installation against localhost:8772. 36 route/viewport checks at 320/390/430px verify no horizontal overflow, loaded images and visible global navigation. Interaction checks cover landing to menu, coffee filter, search, optional extra, quantity, basket calculation, removal and Home navigation. Three mobile screenshots are included. FOND landing/menu screenshots visually inspected.

Production implementation, live data alignment, approved photography, modifier rules and device UAT remain pending design review.
